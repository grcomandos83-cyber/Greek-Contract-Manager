# Οδηγός Χρήσης: Σύστημα Διαχείρισης Συμβάσεων (Contract Manager)

[![Κατέβασμα για Windows](https://img.shields.io/badge/Κατέβασμα-για_Windows-blue?style=for-the-badge&logo=windows)](https://github.com/grcomandos83-cyber/contract-manager-sqlite/releases/latest/download/ContractManager.exe)

Καλώς ήρθατε στην εφαρμογή διαχείρισης συμβάσεων! Η εφαρμογή έχει σχεδιαστεί για να κάνει την παρακολούθηση, την οργάνωση και την αποθήκευση των συμβάσεών σας πιο εύκολη και γρήγορη.

## Τι μπορείτε να κάνετε με την εφαρμογή

- **Καταχώριση & Οργάνωση:** Μπορείτε να προσθέτετε, να επεξεργάζεστε και να διαγράφετε συμβάσεις με λίγα κλικ. 
- **Δυναμικά Πεδία:** Ανάλογα με την κατηγορία της σύμβασης (π.χ. "Ενέργεια", "Τηλεφωνία"), το σύστημα προσαρμόζει αυτόματα τα στοιχεία που σας ζητάει (π.χ. αριθμός παροχής ρεύματος).
- **Αρχειοθέτηση Εγγράφων (PDF):** Κάθε σύμβαση μπορεί να συνδεθεί με ένα ή περισσότερα αρχεία PDF. Μπορείτε να τα ανοίγετε με ένα κλικ, κατευθείαν μέσα από το πρόγραμμα!
- **Έξυπνες Ειδοποιήσεις:** Δεν θα χάσετε ποτέ καμία προθεσμία. Η εφαρμογή σας ειδοποιεί όταν κάποια σύμβαση έχει λήξει ή πρόκειται να λήξει σύντομα.
- **Ιστορικό Εκδόσεων:** Κάθε φορά που αλλάζετε κάτι σε μια σύμβαση, το πρόγραμμα κρατάει ιστορικό. Μπορείτε ανά πάσα στιγμή να δείτε τι είχε αλλάξει ή να την επαναφέρετε στην παλιά της μορφή.
- **Ταχύτατη Αναζήτηση:** Βρείτε αμέσως οποιαδήποτε σύμβαση, αναζητώντας με λέξεις-κλειδιά ή φιλτράροντας τα αποτελέσματα.
- **Στατιστικά:** Το κεντρικό ταμπλό (Dashboard) προσφέρει μια γρήγορη ματιά στο σύνολο των ενεργών, ληγμένων ή επερχόμενων συμβάσεων.
- **Εμφάνιση:** Διαθέτει επιλογές για αλλαγή του θέματος (Χρώματα / Φωτεινό-Σκοτεινό) ώστε να ταιριάζει στα μάτια σας.

## Πώς να ξεκινήσετε

1. Εντοπίστε το αρχείο **`ContractManager.exe`** (βρίσκεται στον ίδιο φάκελο με αυτό το αρχείο οδηγιών).
2. Κάντε **Διπλό Κλικ** για να ανοίξει η εφαρμογή. 
3. *Αυτό ήταν!* Δεν απαιτείται καμία πολύπλοκη εγκατάσταση.

*(Σημείωση: Την πρώτη φορά που θα ανοίξει το πρόγραμμα, θα δημιουργήσει αυτόματα όλους τους απαραίτητους φακέλους για να αποθηκεύει τα έγγραφά σας).*

## Μεταφορά σε άλλο υπολογιστή και Ασφάλεια Δεδομένων

Όλα σας τα δεδομένα αποθηκεύονται τοπικά, στον υπολογιστή σας. Το πρόγραμμα δεν στέλνει τίποτα στο διαδίκτυο. Αν χρειαστεί να αλλάξετε υπολογιστή, ακολουθήστε αυτά τα απλά βήματα:

1. Αντιγράψτε τον φάκελο που περιέχει το εκτελέσιμο `ContractManager.exe`.
2. **Βεβαιωθείτε ότι αντιγράψατε μαζί και τα παρακάτω αρχεία / φακέλους:**
   - **`contracts.db`**: Εδώ βρίσκονται όλα τα κείμενα, οι συμβάσεις και το ιστορικό σας!
   - **Φάκελος `contract_pdfs`**: Εδώ σώζονται τα συνδεδεμένα PDF.
   - **`settings.json`**: (Προαιρετικό) Κρατάει τις ρυθμίσεις εμφάνισης.

Επικολλήστε τα πάντα στον νέο υπολογιστή και απλώς τρέξτε ξανά την εφαρμογή. Όλα σας τα δεδομένα θα είναι εκεί. Το πρόγραμμα φροντίζει από μόνο του, με έξυπνο (αυτόματο) τρόπο, να αναβαθμίζει τις ημερομηνίες και τα δεδομένα σας ώστε να διατηρούνται πάντα ασφαλή.

## Αντίγραφα Ασφαλείας (Backups)

Για να έχετε το κεφάλι σας ήσυχο, μέσα από τις **Ρυθμίσεις** της εφαρμογής μπορείτε να πάρετε ένα Αντίγραφο Ασφαλείας (Backup) της βάσης σας. Αυτό θα δημιουργήσει ένα αντίγραφο στον φάκελο `backups` που μπορείτε να φυλάξετε σε ένα USB ή έναν εξωτερικό δίσκο. 

Επίσης, η εφαρμογή υποστηρίζει Εξαγωγή (Export) σε μορφή αρχείου Excel/JSON, αν χρειαστείτε τα δεδομένα σας για άλλο πρόγραμμα.
